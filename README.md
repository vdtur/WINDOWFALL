# WINDOWFALL

Браузерная головоломка, в которой уровень — это несколько **настоящих окон браузера**.
Шарик живёт в координатах экрана и виден только внутри окон. Двигай и растягивай окна мышкой,
чтобы он докатился от **START** до флага в **EXIT**. Вылетит в пустоту между окнами — сгорит.

**Играть:** https://vdtur.github.io/WINDOWFALL/

## Как играть

1. Открой страницу на ПК в Chrome, Edge или Firefox.
2. Разреши всплывающие окна для сайта (иначе браузер откроет только одно окно).
   Если забыл — игра покажет инструкцию и кнопку «Открыть следующее окно» (по одному окну на клик).
3. Выбери уровень → откроются окна. Расставь их и жми **ПУСК** (или **пробел** в любом окне).

| Клавиша | Действие |
|---|---|
| Пробел | пуск / заново во время полёта |
| R | вернуть шарик в START |
| P | пауза |

Правила:
- Края окон — не стены. Шарик перелетает между окнами, если они стоят рядом или перекрываются,
  а в пустоте может пробыть не дольше ~0,35 с — как раз чтобы перелететь заголовок соседнего окна.
- Окна можно накладывать друг на друга: в зоне перекрытия работает только **верхнее** окно
  (порядок — по последнему фокусу).
- Платформы двигаются вместе с окном. На «живых» уровнях окна можно двигать во время полёта —
  резкий рывок окна подбрасывает шарик. На остальных окна замерзают до конца попытки.
- 🔒 — окно нельзя двигать. Размер окон менять нельзя, кроме отмеченных ◢ — их растягивают за уголок
  внизу справа (содержимое тянется вместе с окном).

Элементы: платформы и скаты, шипы, батут (×1,8), порталы между окнами, зона антигравитации,
вентилятор, монеты (звёзды) и флаг.

## Устройство

Без сборки, без зависимостей — чистые ES-модули.

```
index.html      главное окно (меню, хаб, мини-карта экрана)
window.html     дочернее окно уровня
js/hub.js       открытие окон, игровой цикл, победа/смерть, прогресс
js/child.js     отчёт о положении окна, рендер своего куска мира и шарика
js/sync.js      BroadcastChannel "window-ball"
js/physics.js   шарик, коллизии с отрезками, порталы, зоны (чистый модуль, без DOM)
js/levels.js    10 уровней
js/geometry.js  координаты клиентской области окна на экране
js/sound.js     синтезированные звуки (Web Audio)
tools/sim.html  безоконная проверка, что все уровни проходимы
```

- Hub — единственный источник правды по физике (фиксированный шаг 1/120 с).
  Дочерние окна каждый кадр шлют `rect` своей клиентской области и рисуют шарик по `state` от hub.
- Физика шагает и от `requestAnimationFrame` hub, и от входящих сообщений окон — поэтому игра
  не встаёт, даже если главное окно перекрыто или свёрнуто.
- Угол клиентской области: в Firefox — `mozInnerScreenX/Y`, в Chromium — оценка по
  `outerWidth − innerWidth`, уточняется по первому движению мыши (`e.screenX − e.clientX`).
- Уровни описаны в пикселях «сцены» 1240×680, которая центрируется на экране и уменьшается
  на маленьких мониторах.

## Разработка

Нужен любой статический сервер (BroadcastChannel не работает с `file://`):

```bash
python -m http.server 8737
```

- http://localhost:8737/ — игра
- http://localhost:8737/?debug=1 — все уровни открыты, в окнах видны rect-ы всех окон и вектор
  скорости, кнопка «решение» расставляет окна по эталону
- http://localhost:8737/tools/sim.html — прогон всех уровней по эталонным расстановкам
  и устойчивость к сдвигу окон на ±10/±25 px; в консоли `simAuditLevel(LEVELS[i])` ищет обходы —
  проходится ли уровень, если убрать одно из подвижных окон

## Публикация на GitHub Pages

1. Залей содержимое в ветку `main` (в корне должны лежать `index.html` и `.nojekyll`).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`.
3. Через минуту игра будет на `https://<user>.github.io/WINDOWFALL/`.

Pages для приватного репозитория доступен только на платных планах GitHub — на бесплатном
репозиторий нужно сделать публичным.
