WINDOWFALL

Только для компьютера

WINDOWFALL играется настоящими окнами браузера: их нужно таскать мышкой по экрану. На телефоне так не получится — открой страницу на ПК в Chrome, Edge или Firefox.

Уровень — это несколько настоящих окон браузера. Шарик живёт в координатах экрана и виден только внутри окон. Двигай и растягивай окна мышкой, чтобы он докатился от START до флага в EXIT. Вылетит в пустоту между окнами — сгорит.

  • Окна можно ставить вплотную и даже друг на друга: в зоне перекрытия работает только верхнее окно.
  • Пробел в любом окне — пуск, R — заново, P — пауза.
  • Нужно разрешить всплывающие окна для этого сайта — иначе браузер откроет только одно.

Браузер заблокировал окна

  1. Chrome / Edge: справа в адресной строке значок заблокированного окна → «Всегда разрешать всплывающие окна» → Готово.
  2. Firefox: жёлтая полоска сверху → «Настройки» → «Разрешить всплывающие окна для этого сайта».
